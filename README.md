# Model deployment CI exercise

This 2022 repository is a fork of the [Udacity model deployment starter](https://github.com/udacity/nd0821-c3-starter-code). My contribution is the [GitHub Actions workflow](.github/workflows/pytestflake8.yml), which configures DVC artifact retrieval and runs pytest and flake8 across a Python version matrix.

The workflow and its original dependencies are preserved as a historical exercise. The [course setup notes](COURSE-SETUP.md) describe the broader starter project. The repository records the CI work I added.
